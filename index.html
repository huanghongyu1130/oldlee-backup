OLDLEE 備份

這是內部使用的工廠管理系統的備份工具。它只做一件事：每天把系統資料加密後，存到使用者自己的 Google 雲端硬碟。

隱私權政策

  • 存取範圍：只要求 drive.file 權限，只能讀寫本工具自己建立的備份檔案，看不到雲端硬碟裡的其他檔案。
  • 資料用途：只用來上傳、列出、下載和刪除過期的備份檔。
  • 資料存放：授權憑證只存在使用者自己的主機上，不會傳給任何第三方，也沒有其他伺服器。
  • 加密：備份在上傳前就已經加密，Google 和其他人都無法讀取內容。
  • 撤銷：隨時可以在 Google 帳戶 › 第三方存取權 移除本工具的存取權。

Privacy Policy (English)

OLDLEE Backup is an internal tool that uploads encrypted daily backups of a private factory management system to the user's own Google Drive. It requests only the drive.file scope, so it can access only the files it creates. Tokens are stored solely on the user's own machine and are never shared with third parties. Access can be revoked at any time at myaccount.google.com/permissions.
